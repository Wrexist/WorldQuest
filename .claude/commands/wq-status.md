Report where the project actually stands.

1. Read `docs/plan/phase-0-checklist.md`, `docs/product/roadmap.md` and
   `docs/plan/build-order.md`.
2. Inspect the repo: which packages exist, what's implemented, what's a stub.
3. Check git history for recent direction.

Report:

- **Current phase** and whether its exit criteria are met
- **Done** — what actually exists and works
- **In progress**
- **Blocked** — especially the decisions in the Phase 0 checklist that need a human
- **Next three things**, from `build-order.md`, with reasoning
- **Risks that have moved** since the last review (`docs/plan/risks.md`)

Be honest about the gap between the documentation and the code. Written-but-unbuilt is
normal in Phase 0 and worth stating plainly — it is not the same as done.
