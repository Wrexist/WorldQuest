# Relief map previews

Generated by `node scripts/build-clay-maps.cjs` from the same `GlobeRenderer`,
`atlasTheme`, country geometry, ID raster and Natural Earth II relief texture used
by the interactive atlas. Natural Earth data is public domain; source versions,
checksums and geographic attribution are recorded in
`docs/design/world-atlas/atlas-manifest.generated.json`.

These are rendered maps, not generated geographic illustrations. Each country
highlight uses its verified raster ID and outline. Tiny countries use a locator
dot at their verified anchor, with enough surrounding land to orient the learner.
There are no country names, capital pins or answers baked into the images.

The 640 × 480 WebP files replace the flat locator masks in country pages, optional
study cards and GPU fallbacks. Region previews are shared by Explore, its region
pages and onboarding. Still cards need no GL context or perpetual animation.
The live atlas keeps pan/zoom and scene-specific question disclosure.

To reproduce, install repo dependencies and Playwright Chromium, then run
`pnpm build:clay-maps`. The local build server exposes only its five explicit
renderer inputs and binds to localhost. Output may vary slightly by GPU/Chromium
version; geographic inputs and the native renderer are shared source code.
