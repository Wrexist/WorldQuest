# Platform and header refinement

The circular platform face now has equal width and height. Its progress ring is
centered on the entire raised platform (including the lower edge), with a native
circular border for the empty track. Earned progress overlays the same radius.
The browser review measures both aspect ratios and both center offsets.

Upcoming rows are 96 points instead of 124. The active row is 112 points, with a
smaller companion. Row gaps, bottom padding and the action panel's padding are
tighter so more of the path fits above navigation. The path keeps its clean canvas;
no landscape has been reintroduced.

TopBar now has a tinted rounded surface, an illustrated globe fallback and larger
coin/streak glyphs. Counters have a raised lower edge. Pending streaks remain dim
and their accessibility labels retain the pending meaning. Chosen avatars and all
navigation handlers are preserved. These are the user's actual counts.

The UI UX Pro Max guidance installed in the previous pass continues to inform
spacing, native touch feedback, meaningful motion and large-text checks.
